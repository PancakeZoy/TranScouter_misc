# Data Files

This directory stores the local data artifacts used by the TranScouter reproducibility workflow. Large files are excluded from the repository. They should either be obtained from the public sources below or regenerated with the scripts in `code/data_curation/`.

Keep the directory names and filenames unchanged, since the scripts use these paths.

## Gene embeddings

Place the following files in `data/embeddings/`:

| Local filename | Source |
| --- | --- |
| `scELMo.pickle` | Download the **Gene-GPT 3.5** embedding from the [scELMo library](https://sites.google.com/yale.edu/scelmolib). The direct Google Drive entry is [Gene-GPT 3.5](https://drive.google.com/file/d/17x9jfDorZYqoaG-MZGiduKFzP6663awO/view?usp=drive_link). |
| `GenePT_V1.pickle` | Download `GPT_3_5_gene_embeddings.pickle` from [GenePT Zenodo record 10030426](https://zenodo.org/records/10030426), Version 0. |
| `GenePT_V2.pickle` | Download `GenePT_gene_embedding_ada_text.pickle` from [GenePT Zenodo record 10833191](https://zenodo.org/records/10833191), Version 2. |

## Jiang24

The Jiang24 raw data are distributed as Seurat objects on [Zenodo record 14518762](https://zenodo.org/records/14518762). Convert the five Seurat `.rds` objects to AnnData `.h5ad` format using the SeuratDisk conversion workflow shown in the public [PerturBench Jiang24 curation script](https://github.com/altoslabs/perturbench/blob/main/notebooks/neurips2025/data_curation/curate_Jiang24_step1.R).

Expected raw inputs:

- `data/jiang/raw/Seurat_object_IFNB_Perturb_seq.h5ad`
- `data/jiang/raw/Seurat_object_IFNG_Perturb_seq.h5ad`
- `data/jiang/raw/Seurat_object_INS_Perturb_seq.h5ad`
- `data/jiang/raw/Seurat_object_TGFB_Perturb_seq.h5ad`
- `data/jiang/raw/Seurat_object_TNFA_Perturb_seq.h5ad`

Generated by this repository:

- `data/jiang/raw/jiang24_processed.h5ad`: combined Jiang24 single-cell object.
- `data/jiang/processed/aggregate_sum.h5ad`: Jiang24 pseudobulk object.
- `data/jiang/processed/aggregate_sum_hvg.h5ad`: Jiang24 model input after HVG filtering.
- `data/jiang/processed/top_degs_names.pkl`: DEG names used by evaluation and figure notebooks.
- `data/jiang/processed/top_degs_idx.pkl`: DEG indices used by evaluation and analysis.
- `data/jiang/processed/adata_uns.pkl`: DEG metadata cache used by the random-pairing ablation.
- `data/jiang/processed/aggregate_sum_ctrl.h5ad`: control-only object used by CellOracle.
- `data/jiang/processed/jiang24_ctrl_for_umap.h5ad`: control-cell cache used by the Jiang24 UMAP supplementary figure.
- `data/jiang/splits/split_dict_10Fold.pkl`: Jiang24 cross-validation split dictionary.
- `data/jiang/splits/trainsize/TrainSize_SplitDict_{1..5}_10Fold.pkl`: Jiang24 train-size ablation split dictionaries.

## McFaline

The McFaline raw data are available from [GEO GSE225775](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE225775). The `.h5ad` inputs used here are generated from the GEO supplementary files using the public [PerturBench McFaline-Figueroa23 curation script](https://github.com/altoslabs/perturbench/blob/main/notebooks/neurips2025/data_curation/curate_McFalineFigueroa23_step1.R).

Expected raw inputs:

- `data/mcfaline/raw/gxe1.h5ad`
- `data/mcfaline/raw/gxe2_A172.h5ad`
- `data/mcfaline/raw/gxe2_T98G.h5ad`
- `data/mcfaline/raw/gxe2_U87MG.h5ad`

Generated by this repository:

- `data/mcfaline/raw/mcfaline23_gxe_processed.h5ad`: combined McFaline single-cell object.
- `data/mcfaline/raw/obs_meta.csv`: cell metadata used for UMAP cache construction.
- `data/mcfaline/raw/var_meta.csv`: gene metadata retained with the processed raw object.
- `data/mcfaline/processed/mcfaline.h5ad`: McFaline model input.
- `data/mcfaline/processed/mcfaline_extra.h5ad`: additional genes used by the McFaline correlation baseline.
- `data/mcfaline/processed/mcfaline_ctrl_for_umap.h5ad`: control-cell cache used by the McFaline UMAP supplementary figure.
- `data/mcfaline/splits/split_dict_5Fold.pkl`: McFaline cross-validation split dictionary.
